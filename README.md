# Como executar
python normal pae.
1. `python3 -m venv venv`
2. ative o ambiente virutal, `source/venv/bin/activate`ou `source/venv/Script/activate`.

3. `git clone https://github.com/ilwca/processamento-de-imagens.git`
4. `cd processamento-de-imagens`
5. `pip install -r requirements.txt`
6. Agora excolha o projeto por diretorio e execute o arquivo .py.
